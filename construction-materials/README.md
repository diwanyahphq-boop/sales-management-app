# المثلث · نظام إدارة المواد الإنشائية

نظام متكامل لمخازن ومعارض المواد الإنشائية (اسمنت، حديد، طابوق، رمل وحصى، سيراميك، صحيات، كهربائيات…) يعمل بالكامل من المتصفح كبداية، ومهيأ للتحويل لاحقاً إلى نسخة سطح مكتب أو خادم.

حقوق البرمجة © أصيل الصافي

## التشغيل
افتح `index.html` في متصفح حديث (كروم أو إيدج). عند أول تشغيل تُنشئ حساب المدير، مع خيار إضافة بيانات تجريبية للمعاينة.

## المميزات
- **المدير والمستخدمون:** أدوار جاهزة (مدير، محاسب، مبيعات، أمين مخزن) مع 19 صلاحية قابلة للتخصيص، مثل رؤية الكلفة والأرباح وتعديل الأسعار والإلغاء. يمكن إيقاف أي حساب، ولكل عملية سجل باسم من نفّذها.
- **نقطة البيع:** بيع بالباركود من الماسح أو الكاميرا أو بالبحث، وتسعير مفرد أو جملة للمقاولين، وخصم وأجور نقل وضريبة. الدفع نقداً أو جزئياً أو آجلاً مع تاريخ استحقاق، وتنبيه عند تجاوز سقف دين الزبون أو عند نقص المخزون.
- **عروض الأسعار:** تُحوَّل إلى فاتورة بنقرة واحدة.
- **التوصيل للمواقع:** لوحة بثلاث مراحل (بانتظار التحميل، في الطريق، تم التسليم) مع السائق ورقم العجلة.
- **المواد والمخزن:** باركود Code 128 يُولَّد تلقائياً، وطباعة ملصقات، وحد إعادة الطلب، وتسوية وجرد، وسجل حركة لكل مادة.
- **المشتريات:** إدخال الكميات إلى المخزن، وتحديث الكلفة، وإرفاق صورة فاتورة المورد من الماسح.
- **الحسابات:** كشف حساب لكل زبون ومورد، وسندات قبض وصرف توزَّع على الفواتير الأقدم أولاً.
- **القوائم المستحقة:** تصنيف الديون إلى متأخرة، وتستحق خلال أسبوع، ولاحقة. اختيار جماعي ثم إرسال تذكير عبر واتساب أو SMS بقوالب تُملأ تلقائياً ({الاسم} {المبلغ} {أيام_التأخير}…)، مع طابور إرسال وسجل للرسائل.
- **الماسح الضوئي والأرشيف:** سحب وإفلات أو لصق من الحافظة أو كاميرا الهاتف، مع محرر يحسّن الصورة لتبدو كمستند ممسوح (مستند، تحسين، رمادي، تدوير) وربطها بزبون أو مورد.
- **ماسح الباركود:** أي جهاز قارئ USB أو بلوتوث يعمل كلوحة مفاتيح يُقرأ في أي شاشة بلا إعداد.
- **التقارير:** المبيعات والأرباح والمقبوضات والمشتريات، والمبيعات حسب الصنف والمادة والمستخدم، مع إمكانية الطباعة.
- **مزايا إضافية:** لوحة أوامر (Ctrl+K)، واختصار F2 لفاتورة جديدة، ورسائل داخلية بين المستخدمين، ووضع ليلي، وتصميم متجاوب للهاتف، ونسخ احتياطي واستعادة.

## الترخيص
- نسخة تجريبية مدتها 14 يوماً بحد أقصى 40 مادة، ثم يُطلب التفعيل. البيانات تبقى محفوظة.
- رمز البرنامج في مولد الأرقام التسلسلية: **`BLD`**

## حدود النسخة الحالية (HTML)
- البيانات محفوظة في متصفح الجهاز: localStorage للسجلات وIndexedDB للمستندات. خذ نسخة احتياطية بانتظام.
- تسجيل الدخول والترخيص يعملان داخل الصفحة، فهما للحماية من النسخ العابر فقط. الحماية الحقيقية والعمل على عدة أجهزة تحتاج خادماً.
- لا يمكن للمتصفح قراءة الماسح الضوئي مباشرة عبر TWAIN/WIA، لذلك يُحفظ المسح كملف ثم يُسحب إلى الصفحة أو يُلصق فيها. القراءة المباشرة تتاح في نسخة سطح المكتب.
- الرسائل تُفتح جاهزة في واتساب أو تطبيق الرسائل، ويضغط المستخدم «إرسال». الإرسال الآلي الكامل يحتاج ربط مزوّد رسائل (واتساب للأعمال أو SMS) في نسخة الخادم.

## البنية
```
index.html
css/app.css             الهوية والتصميم
js/core.js              أدوات، SHA-256، الترخيص، الباركود، الأيقونات
js/data.js              قاعدة البيانات ومنطق العمل والبيانات التجريبية
js/ui.js                الجلسة، النوافذ، الهيكل، الماسح، لوحة الأوامر، شاشات الدخول
js/views-sales.js       لوحة القيادة، نقطة البيع، الفواتير، التوصيل
js/views-accounts.js    الزبائن، الموردون، القوائم المستحقة، السندات، الرسائل
js/views-admin.js       المواد، المشتريات، المستندات، التقارير، المستخدمون، السجل، الإعدادات
```
منطق العمل في `data.js` منفصل عن الواجهة لتسهيل نقله إلى أي لغة أو إطار لاحقاً.
