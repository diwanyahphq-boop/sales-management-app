# برنامج إدارة المبيعات والأقساط الذكي

## نظام الذكي لإدارة المبيعات والأقساط - تطبيق سطح مكتب

تطبيق Electron متقدم لإدارة المبيعات بالتقسيط مع دعم كامل للعمليات المالية والمتابعة.

### المميزات ✨

- 🔐 **نظام حماية متقدم** - تسجيل دخول وحماية البيانات
- 📊 **لوحة إحصائيات حية** - متابعة الأموال والديون بشكل فوري
- 💾 **قاعدة بيانات محلية** - حفظ آمن للبيانات على الجهاز
- 📄 **إنشاء فواتير** - طباعة فواتير احترافية
- 📊 **تصدير Excel** - تقارير شاملة وسهلة الاستخدام
- 📤 **نسخ احتياطية** - حماية البيانات ضد الفقدان
- 🔍 **بحث متقدم** - البحث السريع عن العقود والعملاء
- ⚙️ **سهل الاستخدام** - واجهة عربية بسيطة وجميلة

### المتطلبات

- Node.js v14 أو أحدث
- npm أو yarn

### التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/diwanyahphq-boop/sales-management-app.git
cd sales-management-app

# تثبيت المكتبات
npm install

# تشغيل التطبيق
npm start
```

### البناء والتجميع

```bash
# بناء نسخة Windows
npm run build-win

# بناء نسخة macOS
npm run build-mac

# بناء نسخة Linux
npm run build-linux
```

### الاستخدام

1. **التهيئة الأولى**: عند تشغيل التطبيق لأول مرة، قم بإنشاء حساب المدير
2. **إضافة عقود**: استخدم نموذج البيانات لإضافة عقود جديدة
3. **متابعة الأقساط**: راقب الأموال المستلمة والديون المتبقية
4. **التصدير**: يمكنك تصدير البيانات إلى Excel أو طباعتها
5. **النسخ الاحتياطية**: احفظ نسخة احتياطية من بيانات بشكل دوري
